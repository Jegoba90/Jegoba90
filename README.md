# I build products and ship them.

Most of them share one idea: **AI should not only be intelligent. It should be verifiable.**

- 🛡️ **[Ganimedes](https://github.com/Jegoba90/Ganimedes-Project)**: a security gateway for AI agents. It audits, blocks and holds for approval what an agent does before it touches your systems. · `Go`
- 📊 **[CryptoCapi](https://cryptocapi.com)**: crypto market analysis where deterministic math overrules the AI. Every PRO insight carries a SHA-256 seal anyone can check. · `TypeScript` `Python`
- 🔌 **[CryptoCapi MCP](https://github.com/Jegoba90/cryptocapi-mcp)**: verifiable crypto market analysis as native tools for any MCP agent. Four engines, demo key included, no signup. · `TypeScript`
- 🛒 **[El Cafetal Foods](https://www.elcafetalfoods.workers.dev/)**: an online store with no cart and no checkout. Every order closes on WhatsApp. · `Astro` `TypeScript` `Zod`
- 🏃 **[Pasá la Posta](https://pasalapostarun.com/)**: race-kit pickup and delivery for runners in Buenos Aires. They skip the Expo line and the kit arrives at their door. · `TypeScript` `Supabase` `Cloudflare Workers` `Apps Script`
